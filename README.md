# Sistema de Estacionamiento

## Descripción

Programa desarrollado en Java para administrar un estacionamiento de 10 x 10.

El sistema permite controlar el ingreso y retiro de vehículos, realizar el cobro correspondiente y consultar el estado del estacionamiento.

## Funcionalidades

- Ingreso de vehículos mediante placa.
- Validación de placas.
- Cobro de tarifa fija de Q10.00.
- Cálculo de cambio.
- Retiro de vehículos.
- Búsqueda de vehículos.
- Visualización del estacionamiento.
- Conteo de espacios libres y ocupados.
- Cálculo de la ruta más corta entre la entrada y la salida.
- Control de ingresos acumulados.

## Tecnologías utilizadas

- Java
- Git
- GitHub

## Ejecución

El programa puede ejecutarse desde la clase principal del proyecto.

También se incluye un archivo `.jar` para ejecutar el programa sin necesidad de abrir el código fuente.
